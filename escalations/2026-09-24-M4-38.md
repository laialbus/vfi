**Doing.** Wiring `periods::periods` and `standing::stands` into the shape the
accepted `docs/adr/what-normalize-emits.md` hands the next stage, crossing
`Stands` into `vfi_contracts::canonical_concepts::Resolution`. I re-derived

**What stopped it.** The task says that where the crate builds something v2 has
no place for, the run does not invent a crossing, and that unless M4-37's merged
surface already states one it stops. It states none, and there are two such
states, not the one the task names.

*A Rule 3 tie.* `standing::Unsettled` carries `attempted` — the answering
filings whose attempt came to `Unknown`, and only those — beside `undecided`.
v2 builds an `Unknown` from `Attempts::in_filings(first, rest)`, which holds at
least one `Attempted`, and `undecided_by` hangs the tie on an `Attempts` that
already exists. Where Rule 3 ties and every answering filing produced a
`Value`, `attempted` is empty: there is no `first`, so there is no `Attempts`
and nowhere to put the tie. The landed test
`a_same_day_tie_no_form_breaks_is_unknown_carrying_both_accessions_whatever_the_figures_say`
asserts exactly that emptiness, and I reproduced it at two filings sharing a
`filed`, reading `us-gaap:ShortTermInvestments` at one instant under forms
`10-K` and `10-Q`, neither amending the other: `attempted` 0, `undecided`
`Tie([...])`. This is not a defensive branch — the task asks for a hand-written
tie case.

*`Undecided::Undated`,* which the task names. It carries the accessions whose
`filed` does not read as a date, and v2's `Unknown` names a tie and nothing
else. The same emptiness applies: those filings produced values, so they are
not in `attempted` either. No merged fixture reaches it — 0 across every
admitted period of the three filers below — but it is reachable, since a
concept can take its value from an undated filing at a period another concept
admits.

**The readings that would cross, not taken.**

- Cross a tied or undated filing as `Attempted::in_filing(accession,
  Attempt::that_ran(vec![]))`. v2 reads that as an attempt that considered no
  candidate; these considered one and found it, so it would make the two cases
  v2's own `Unknown` line keeps apart read alike.
- Drop the tie and cross the attempts that exist. It loses the tied accessions
  v2's `carries` line asks for, and where every answering filing produced a
  value there is still no `first`.
- Refuse the filer's whole history where either state is built. It invents
  nothing, but it costs a filer's history to one unreadable `filed`, and v2
  makes no room for a filer that resolves to nothing.
