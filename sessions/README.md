# Sessions

One file per successful run, named `<YYYY-MM-DD>-<task-id>.md` —
`2026-07-28-M1-04.md`. A run that claims no task uses a short slug for its
subject instead (`2026-07-28-lead.md`); if that name is taken, append `-2`, then
`-3`.

What belongs: the task, the branch, and what changed, in a few lines. What does
not: how you got there, or anything already in the commit, the diff, or the pull
request.

Entries are never pruned. They are the durable record that makes deleting task
files and escalation files safe.
