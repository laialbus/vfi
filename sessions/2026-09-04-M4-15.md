# 2026-09-04 — M4-15

Branch `M4-15`. `vfi-contracts` gains `canonical_concepts`, the published
vocabulary at v1 as Rust: the three states, the five kinds, the twenty-eight
concepts and each concept's measure, unit, sign, applicability and silence. Six
tests compare the type against `v1.toml` — names off the declaration, names out
of the file — and one walks every concept against every kind to show the only
route to `NotApplicable`. No contract byte changed and nothing was rewired.

`NotApplicable` takes an `Excluded`, which only a concept's own clause hands out
and only for a kind it omits; `Unknown` takes an `Attempt`. Neither witness can
be made from the other's inputs, and `excluding` takes a kind rather than an
optional one, so an unestablished kind has nothing to ask.

A new `names!` macro carries a closed set of names the way `shapes!` carries a
closed set of shapes. The TOML reader the comparisons use moved out of
`fetch_normalize` into the crate root, so the second contract reads the same one
rather than a copy; that module's tests are otherwise unchanged.

For the decider. Two readings the bytes do not state outright, both deliberate.
`Value` carries the amount as well as the three the file names it carrying —
"resolved to an amount" is what the state means, and it crosses as the published
characters because the crate depends on nothing that could hold a decimal.
`Silence::Conditional` names the reading and not the condition: `zero_when` and
`unknown_when` are prose the file publishes with the concept, and a copy here
would be a transcription nothing compares.
