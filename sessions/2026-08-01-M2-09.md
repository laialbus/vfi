# 2026-08-01 — M2-09

Branch `M2-09`. The gate set is written down once in `scripts/gates.sh`, as
data, and checked against the `gate_*` functions the file defines before any
gate runs: a name in the list with no function, or a function the list does not
name, goes red naming the difference. Both the gate loop and the proof loop read
that list, so deleting a gate used to delete its own proof and finish green.
Removing one now costs a second, visible line in the same file.

The check is proved like a gate — the scratch copy drops `purity` from the list
and must go red — so it runs in CI with the rest.

`scripts/gates.sh` is protected, so the pull request needs the `human-approved`
label.
