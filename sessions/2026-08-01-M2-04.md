# 2026-08-01 — M2-04

Branch `M2-04`. `scripts/gates.sh` gains the `contracts` gate. The compatibility
rule is written down in the runner, beside the checker that reads it: a contract
is a directory under `contracts/`, its surface at version N is the one
`v<N>.*` file, and `versions` records each published version with the sha256 of
that file. A published version is frozen and every change to one counts as
breaking, because nothing mechanical can tell an addition from a removal without
reading a format that is not decided yet; the answer to a change is `v<N+1>`.
Nothing is created under `contracts/` — the gate runs its real check over the
contracts that exist, which is none, and says so.

The proof runs both ways: a fixture contract that bumped correctly must leave
the copy green, and the same change written over `v1` instead must turn the
single command red. The runner grew `accept_<gate>` for that first half. The
rest of the rule is a case table beside the proofs, run in-band with the gate.

`scripts/gates.sh` is protected and this task owns it, so the pull request needs
the `human-approved` label.
