# 2026-08-02 — M2-06

Branch `M2-06`. `scripts/gates.sh` gains the `benchmark` gate, last, which
completes the set AGENTS.md names. It reads `benchmarks/` the way `fixtures`
reads `fixtures/` and runs each benched stage's `bench` target in release.

The baseline is committed and is therefore checked on machines it was not
recorded on, so none of what it records is a wall clock. Two measurements
instead: counted work — allocations and bytes over a fixed workload, identical
on every machine, so a green run is repeatable by construction rather than by a
threshold wide enough to swallow the variance — and cost, the stage's time over
the time of a plain copy of the same bytes measured in the same run, where the
machine's speed is in both halves and divides out. Counted work is the sharp
one, at 5%. Cost is the blunt one, at 10x, and exists for what counted work
cannot see: a slowdown that allocates nothing. The gap between them — slower by
a little, allocating nothing — needs a per-machine baseline, which is not a
thing that can be committed; the harness header says so rather than leaving it
to be found.

Thresholds are data in `benchmarks/thresholds`, each with its reason beside it.
The 10x is sized off measurement: ~200 local runs spread 0.92 to 1.47, the
widest with the cores oversubscribed, and a full `gates.sh` run measures this
ten times over. The proof injects a per-call allocation that leaves the output
untouched, so `fixtures` stays green and only this gate goes red; an injected
`sleep`, which the counters cannot see, was checked separately and the cost
measure caught it at 546x.

`benchmarks/` is a new home and `docs/layout.md` names it, per the task. It is
separate from `fixtures/` because a baseline is not an expected result: a
fixture that no longer matches is wrong, a measurement that no longer matches
may be either a regression or a stage that legitimately costs more, and the gate
reports that rather than deciding it.

`scripts/gates.sh` is protected and this task owns it, so the pull request needs
the `human-approved` label.
