# 2026-10-05 — M5-04

Branch `M5-04`, re-run of #273 from its commit. New gate `ambient`, after
`purity`, reads every Rust file under `crates/analyze/` for the names in
`ambient_names`, each tagged filesystem, environment, clock, process or
randomized-hasher. Changed from #273: `Instant` is no longer read bare, so
`Period::Instant` passes. The clock is read as `std::time`, `time::Instant`,
`Instant::`, `SystemTime`, `UNIX_EPOCH`, with a plant for each narrowed form.
The accept copy carries the contract's `Period` match. Not read: aliases, and
`Instant` as a bare type through a nested group import.
