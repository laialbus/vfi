# 2026-07-31 — M1-07

Branch: `M1-07`

`tasks.sh` grew a `claim <id>` entry point: it pushes the task's branch, then
re-reads origin and deletes its own ref when the claim stands beside one it may
not — an exclusive claim next to any other, in either direction. A lost claim
is exit 4, distinct from a broken queue (3) and an unreachable origin (1).

A claim counts only when the push created the ref. git calls a push onto a ref
already at that commit a success, so the plain push two runs make from the same
base commit could report another run's claim as its own.

`available` is unchanged.
