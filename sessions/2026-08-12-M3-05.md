# 2026-08-12 — M3-05

Branch `M3-05`. `vfi-fetch` gains `ledger`: the `FilerLedger` interface with the
ADR's two operations, one `Record` carrying every field the ADR fixes, and an
`InMemory` implementation for tests. Nothing persists yet — the journal is
M3-06, and both operations already return `Result` so it lands behind the
interface unchanged.

What the types refuse: a verdict with no step, a rejection with no reason, a
reason composed as prose at the call site (the rule is `&'static str`, defined
beside the step that issues it), and a transport failure written as a rejection
— `Unjudged` is its own variant. A record's moment is given rather than read
from the machine, so a test pins one without waiting on a clock. No workspace
edge added, no dependency added, no test on disk or network.

One for the decider: `ledger` is a public module rather than more names at the
crate root, which is a departure from how this crate has exported so far — the
reason is in `lib.rs`. Its constructors are public so M3-07's tests can build
the record they expect, but a `Record` still needs a `Source`, and a `Source`
is only made by a request this stage sent.
