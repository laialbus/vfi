# 2026-08-01 — M1-10

Branch `M1-10`. `scripts/tasks.sh sweep` releases claims left on origin by runs
that were killed outright — the failures the wrapper's exit trap does not
survive. `run.sh` already calls it in the decider's preflight.

Dead is ruled in, not guessed: an open pull request or a claim origin saw
recently is kept, and so is one origin cannot date, each with the reason
printed. Age comes from origin's activity record, because a claim points at
main's tip and its commit date says nothing about when it landed. The delete
carries a lease on the commit the claim was read at, so a live run pushing
mid-sweep refuses it.

Nothing else changed: `available` and `claim` were diffed against the old script
over fifteen fixtures and differ only in the usage listing naming the new verb.
