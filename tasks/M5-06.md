GOALS.md's last three M5 criteria. The first is that every free parameter
arrives as a setting and every default states its reason. The second is that
each result records the settings and method version it was computed from. The
third is that a metric with no price is absent with a reason and never a wrong
number. Anchor 5 adds that nothing arbitrary enters the derivation. Every
metric task waits on the answers, because each one is a function whose
signature is this record. So does the literal lint anchor 5 names, because it
cannot know which literals to allow until the record says where constants and
defaults live.

`contracts/canonical-concepts/v2.toml` leaves two things here by name, in its
`[elsewhere]` table. One is "how an absent input makes a metric absent", which
it assigns to analyze. The other is "thresholds and defaults", which it
assigns to the settings layer. This record is where both are decided.
