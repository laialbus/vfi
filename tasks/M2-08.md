This is M2's last criterion in GOALS.md. The interface that must stay
responsive does not exist yet, so what this task proves is the seam: the
engine's shape lets a slow job and a live caller coexist. If proving that
honestly seems to require building any part of the shell, stop and escalate —
that would be a scope question for a human, not a judgment call.

A prior delivery was rejected on scope alone, not on the merits: it wrote the
root manifest, which this task did not then own. That work is preserved at
refs/pull/59/head and at refs/heads/escalated/M2-08-20260804-222806 — the next
run redelivers it rather than rebuilding it.
