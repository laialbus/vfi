with the pull request deferred to a background monitor that no headless
session survives to hear. The wrapper caught it after the fact and a human
repaired it by hand; the gate corrects it in-session, while the agent that
has the context still exists. The destination is never-grantable, so this
task ends at the draft — installation is the human's, with the ADR as the
sign-off.
