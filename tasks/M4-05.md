  - The published file states what `docs/adr/canonical-concepts.md` says v1

  - It carries every concept the two records define and no concept neither

  - It states no tag a concept maps from, no metric that consumes one, and no

    records, and the settings layer's.
  - The version record holds exactly one line, `v1` and the sha256 of the
    published file as committed, and nothing else.
  - The file is published in the format and extension the first contract already
    uses. The format is one decision for every contract in the repository, made
    by whichever landed first, not remade here.
  - The contracts gate reports two contracts checked against the versions they
    publish. Nothing already published is edited and nothing the version records
    name is deleted, so the first contract's bytes and digest are exactly as
    they merged.
  - Nothing is implemented: no code under `crates/`, no registry, no mapping,
    and no third contract.

Both records that decide this vocabulary are settled by the time this can be
claimed — the set and its three states in `canonical-concepts.md`, the questions
it left open in the record M4-04 proposes. This transcribes the result onto the
surface `contracts/canonical-concepts/`, where the gate freezes it: from the line
in the version record onward, a concept's meaning costs a version rather than a
diff.

It depends on M4-03 for two things, neither of them the file's content. A
directory under `contracts/` has to mean one thing before a second contract lands
in it, and the file format for every contract in the repository is settled by the
first one published.

The hook grants this write because the task file on origin/main lists
`contracts/canonical-concepts/` under `owns` — but that grant reaches the file
tools only. A bash write is exempted only where the granted entry equals the
protected entry `contracts/`, which this one deliberately does not, so the
surface is written with the file tools. The merge needs the human-approved label
that every protected-path change needs, and no agent may apply it.

Exclusive because the canonical concept definitions are a shared surface, which
WORKPLAN.md single-threads.
