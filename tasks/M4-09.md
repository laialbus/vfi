The record that decides this is accepted: the tag mapping is data under
`registry/`, one file per concept and one per filer, TOML, versioned by the
digest of its own bytes, reached through one interface. Nothing of it is built.
Normalize is still the stub that hands a filing back unchanged, and the
milestone's "mapping happens through a versioned registry with per-company
overrides — data, not branching code" has a decision behind it and no bytes.

This is the concept half: the general mapping, the accounting that proves it
covers the published vocabulary, and the gate that refuses a registry the next
change would corrupt. The content is transcription — the accepted record lists
what reaches each of the twenty-eight concepts, element by element, and names the
elements it deliberately leaves out and why. Transcribe the decision; do not
re-derive it, and do not add an element the record does not list. A tag left out
resolves through to the concept's silence reading and costs precision. A tag
wrongly listed is a wrong number that looks right, which is the failure this
milestone exists to prevent.

The gate is the part that is not transcription, and it lands with the data
because a new surface with no gate over it is itself an escalation. Two of its
checks are worth reading the record twice for: the concepts and kinds it
validates against are read out of the published vocabulary rather than copied
into the checker, so the day a twenty-ninth concept publishes the registry goes
red until it is accounted for; and the rule id is rendered from the fields that
make a rule what it is, so it cannot be mistyped, cannot be copied onto a second
rule, and cannot drift from what it names.

Two mechanics, so they are known before the run rather than during it. The gate
file is a protected path, granted to this task because this file lists it under
`owns` — the copy on origin/main is what grants it — and a protected path that
actually changes needs the human-approved label at merge, which no agent may
apply. `registry/` itself is deliberately not protected: the record chose a home
where adding a tag and writing an override cost no signature, and that is the
property that keeps the mapping from turning back into branching code.

Exclusive because it rewires shared machinery — a new top-level directory, the
file that maps the tree, and the gates — which WORKPLAN.md single-threads.

What follows and is not in this diff: the per-filer half and its checks, the one
interface the registry is reached through, and resolution itself, which cannot be
written until the record that chooses among several matching rules exists.
