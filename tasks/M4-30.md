The record M4-23 proposes names, under its own Consequences, a case it does not
decide: a later thin filing that mentions a period at all resolves
`short_term_investments`, and the two dividend concepts on their pair
condition, to a `Value` of zero from silence, and under Rule 3 a `Value` beats
nothing. The first clause of Rule 3 holds back an `Unknown`, and a silence zero
is not one, so the zero displaces a figure an earlier filing read from a fact.
Neither merged fixture reaches the case, so nothing would go red if an
implementation got it either way. The 2026-09-12 decider sweep carried it for a
human with one recommendation: its own record, beside the vocabulary's silence
readings, before the task that implements Rule 3 is queued. This is that record.

It is a decision of its own because the vocabulary's silence test — that
silence reads as zero only where a wrongly-read zero cannot flatter — was
argued inside one filing's fact set, and the case here is two filings that
answer one period disagreeing about whether the filer said anything at all.
Which of them a reader believes is neither candidate choice, which is settled
inside one filing, nor alignment as M4-23's record states it, which prefers by
nothing but `filed`, `form` and `accession`. The reading it takes is the
proposer's to argue and the decider's to weigh; the acceptance above asks only
that it be one reading, stated once, placed where it belongs, and that it
distinguish attempts by how they were set and never by their figure.

Nothing implements it here. It depends on M4-23 because it reads Rule 3 as that
record states it, and it must read the accepted text, not the proposal.
Whatever implements Rule 3 depends on this record being accepted, and the
planner orders it so.
