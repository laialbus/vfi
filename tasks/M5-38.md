GOALS.md's fourth M5 criterion names returns on capital.
`docs/adr/capital-employed-invested-capital-and-nopat.md`, accepted on
2026-10-16, forms capital employed once as `total_assets` less
`current_liabilities`, names return on capital employed as
`operating_income` over its average, before tax, and puts every term the
two capital returns read in one module that `debt_to_equity` is moved
onto. The period record names the metric averaged. With the seeks and the
averaged read built by M5-29 and the term-before-mean shape built by M5-33,
this metric adds one module, two terms, one entry and one quotient.

Why this split. The record makes the module one, but its five terms serve
two metrics, and return on invested capital alone needs eight concepts,
thirteen reads and four conditions. So the module is created here with the
two terms this metric and `debt_to_equity` read, and M5-39 adds the three
that return on invested capital reads to the same file. Each term is still
formed once, in the one module.

Why no open primary. Under `sources-a-task-can-read.md`, the origin is a
closed book, named by chapter alone. The planner looked for the same
statement in a copy a run can open and found none: the CFA Institute's
published list states returns on debt plus equity, which the record argues
against as this term. So the record's statement is the axiom, and the
documentation says the book was not read.

It depends on M5-37 because every task in the chain owns
`crates/analyze/`, and M5-37 is the last queued.

If the metric cannot be built without a seventh reason, a change to a
contract, to `method.rs`, to `settings/` or to the entry shape M5-18 fixed,
or if moving `debt_to_equity` onto the module changes any outcome, that is
an escalation.
