The fetch → normalize surface is published and frozen, and nothing in the
engine can read it. `docs/adr/fetch-normalize-contract.md` decides what crosses
the boundary; `docs/layout.md` decides where the code that carries it lives —
"the Rust type the stages compile against ... lives under `crates/` like any
other crate — `crates/contracts/`, package `vfi-contracts`, import path
`vfi_contracts`. No such crate exists yet; the task that writes it creates it
there." This is that task. M4-03 named it first among the gaps it left, and the
retrieval that follows cannot hand anything across a boundary that has no type.

The check is the part that is not transcription. A hand-copied type is a second
representation of a value defined elsewhere, and the anchor that governs those
does not ban the copy — it bans the unchecked copy: one is generated from the
other, and CI fails if the generated copy drifts from its source. Either shape
satisfies that, and choosing between them is inside this task. What is not
inside it is shipping the type with nothing comparing it to the bytes: that is
the drift M4-03 named, and a gate that does not yet exist for something you
changed is an escalation rather than a shipped change.

Two mechanics worth knowing before the run rather than during it. The gate file
is a protected path, granted to this task because this file lists it under
`owns` — the copy on origin/main is what grants it, so the grant is live the
moment this task merges into the queue. And a protected path that actually
changes needs the human-approved label at merge, which no agent may apply; if
the check can be carried by a gate that already exists, that reading does not
wait on a signature.

The dependency edges are deliberate and not a convenience. `scripts/gates.sh`
says of that list that "adding an edge here changes the shape anchor 2 fixes, so
it belongs to a task that says so, never to a task that wants one." This task
says so: `vfi-contracts` is not a stage, it is a leaf that depends on nothing,
and the layout already decided the stages compile against it — permitting that
edge is the mechanical consequence of a decision already made, and it adds no
edge between two stages. Anything that would allow a stage-to-stage edge anchor
2 does not already allow is a different decision and above this task.

Exclusive because it rewires shared machinery — the workspace manifest and the
gates — which WORKPLAN.md single-threads.

What follows this task and is not in it: the retrieval that produces the
contract's value, the funnel's fourth step that calls it, and the type for the
canonical concept vocabulary, whose shape belongs with the task that first reads
a concept rather than with this one.
