title: Gate the dependency direction
milestone: M2
owns:
  - scripts/gates.sh
depends_on: [M2-01]
exclusive: yes
acceptance:
  - The gate fails when the crate dependency graph contains any edge other
    than the allowed forward ones — fetch → normalize → analyze → store, per
    anchor 2. The allowed edge set is written as data in one place, where the
    gate reads it.
  - A wrong-direction edge that is not a cycle is caught. The compiler already
    rejects cycles; this gate catches the backward edge the compiler accepts.
  - Proof-of-catch, a scratch copy with a backward edge injected turns the
    single command red, running with the gates in CI.
  - The gate runs from scripts/gates.sh and CI runs the same command.
---

Helper scripts or data this gate adds belong to it and live under scripts/,
invoked only through gates.sh — one entry point per purpose, per
docs/layout.md.
