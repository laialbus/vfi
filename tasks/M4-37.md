`docs/adr/what-normalize-emits.md` is accepted, Structural, and this is the
task it hands on. Two surfaces cannot hold what the stage emits once it runs
over a filer's history: the published vocabulary's boundary carries "one of the
three states below per concept, per filer", which leaves no room for a history
of periods, and its `Value` asks for a source tag and a filing that an asserted
value and a silence-supplied zero do not have. The record decides the shape and
the version; this task writes the bytes.

The record says what the diff is, down to the table of four lines, and the
acceptance above transcribes it rather than adding to it. What a `Value` and an
`Unknown` carry, the period shapes restated rather than referred to, the one
bump taken and the two declined, and the Rust beside the bytes moving to v2 as
M4-25 moved the boundary on the other side.

Exclusive, and the only exclusive task in this batch, because it writes a
contract. The path is protected and grantable: the hook allows the write
because this file, as committed on `origin/main`, lists it under `owns`, and
the pull request still needs the human-approved label on the server, which no
agent applies.

The two rules in code — M4-35 and M4-36 — need none of this, and this needs
neither of them: they settle what a concept comes to and which periods a filer
has, in the crate's own types, while this settles what the boundary publishes.
They are not ordered against each other by `depends_on` because an exclusive
task never runs beside another claim, so whichever lands first, the next run
branches from it.

Not in this diff: the stage running end to end and writing into this surface,
which is the task that follows; and the six normalize golden fixtures, which
the record also fixes the content of and which wait on the wiring.
