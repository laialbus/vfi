acceptance:
  - A deny-list for the analyze crate exists as data, defined in one place,
    covering what anchor 4 bans reaching from analyze — network, filesystem,
    clock, randomness, environment, and effectful logging.
  - The gate fails when vfi-analyze's resolved dependency tree, direct or
    transitive, links anything the list names.
  - Proof-of-catch, a scratch copy with a denied dependency added to analyze
    turns the single command red, running with the gates in CI.
  - The gate runs from scripts/gates.sh and CI runs the same command.
---

Anchor 4's enforcement clause names this mechanism: analyze cannot even link
the libraries that would let it reach the outside world. The crate is empty
today, so the gate passes on main by running the real check over the real
tree, not by being stubbed.
