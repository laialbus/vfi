`contracts/canonical-concepts/v1.toml` publishes three states, and M4-15 compiled
them into a type that makes each constructible only from a witness the other two
cannot obtain. Nothing in the engine constructs any of them yet, and one of the
three has no other way in: `NotApplicable` is built "from a filer kind together
with the applicability clause below that excludes that kind, and nothing else. No
filing is consulted." The surface goes further and fixes the order — "applicability
is asked first ... so a lookup failure has no path to NotApplicable" — which is
the milestone's own requirement that a correct absence and a mapping that failed
are never confused.

`docs/adr/candidate-choice.md` reads the same order from the other side. Of the
four things settled before its rule runs, this is the first: "Applicability is
asked first, by the vocabulary", and the rule "cannot produce `NotApplicable`,
for the reason the vocabulary gives ... a concept that reaches this rule at all
is one the kind admits." So this is not a step inside resolution. It is the gate
in front of it, and it belongs to the vocabulary rather than to the registry —
which is why it reaches neither the registry nor a filing, and why a diff that
made it consult either would be answering a different question.

The kindless filer is the case worth writing a test for even though the code for
it is one branch. A filer with no file in the registry has no kind, and the
temptation is to read that as "no kind admits it". The published surface reads it
the other way — every concept resolves through the attempt, "never to a correct
absence nobody established" — because the claim `NotApplicable` makes is positive
and nobody has made it. Imprecise and safe, in the direction this milestone
always takes.

Not in this diff, and named so the run does not drift: where the kind comes from.
`docs/adr/tag-concept-registry.md` puts it in the filer's file and says that half
is assertion-only, but the interface it fixes takes a kind as an input rather
than answering one, and no filer file exists yet. Nothing here needs that
settled — the kind is an input, as it already is next door. The attempt itself is
also not here: which rules are eligible, which facts answer a period, and how
candidates settle are three other tasks.
