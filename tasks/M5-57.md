`docs/adr/README.md` says a record that supersedes part of another "is
listed here so a reader of the older record can find the newer one", and
`docs/adr/share-basis-rule-dates.md`, accepted on 2026-10-26, supersedes
one sentence of `docs/adr/which-duration-precedes-a-duration.md` and asks
for its row by name. No task owned the README, so the decider has carried
the missing row as open since that acceptance. This task owns it.

It depends on nothing and owns one file no other queued task owns, so it
runs beside the others.

If the row cannot be written without changing another line of the README,
or if the two records on reading disagree about which sentence is
superseded, that is an escalation.
