acceptance:
  - Reading the queue refuses, at exit 3 with the offending file and reason
    named, each of these; a refusal covers the whole queue, as malformed
    frontmatter already does.
  - Two queued tasks whose owns overlap while neither depends on the other,
    directly or through other queued tasks, and neither is exclusive. Two
    owns entries overlap when they are equal or when one is a directory
    prefix of the other — a string prefix that is not a path boundary is
    not an overlap.
  - A depends_on cycle among queued tasks.
  - A task whose id does not match its filename.
  - Not a refusal, pinned as-is — a depends_on naming an absent task still
    reads as satisfied: absence is the merge record. Catching a typo in a
    dependency needs history the checked tree does not carry; it belongs to
    queue review, not to this gate.
  - gates.sh gains a queue gate that runs these checks against the
    repository's own tasks/ directory on every suite run — green on an empty
    queue, red the moment a structural violation lands on a branch — and
    carries its proof-of-catch like every other gate.
  - Corpus cases pin each refusal and each near-miss acceptance — overlap
    ordered by depends_on, overlap where one task is exclusive, a
    dependency on an absent task, and sibling names that share a string
    prefix but not a path boundary, which must not read as overlap.
    Nothing proved gets narrower; every existing case still passes.

The planner role (installed as prompts/planner.md, outside this repository)
makes the queue agent-written. What a human eye caught while humans wrote
task files — an owns collision, a dependency cycle, a copy-pasted id — must
become a refusal, because from now on the eye that writes is the machine's.
These checks need the owns list, which read_frontmatter's validated view
does not yet carry; extending that view is part of the work, under the same
rule the parser already follows — a field that looks set and is not is the
fail-open case.

scripts/gates.sh is protected: the PR merges only with the human-approved
label, applied by a human hand.
