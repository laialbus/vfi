`docs/adr/what-analyze-takes-and-returns.md`, accepted on 2026-10-03, publishes
what the caller hands store at `contracts/analyze-store/`, so that a stored
result carries the history and crossing it read and the premises it was
computed under, and can be replayed. GOALS.md's eighth M5 criterion, that each
result records the settings and method version it was computed from, and the
ninth, that a metric with no price is absent with a reason, are read off this
surface.

`contracts/` is protected and grantable, so this task lists its directory under
`owns`. The pull request merges only with the `human-approved` label, applied
by a human hand. It runs alone because a contract is a shared surface.

It depends on M5-11 because it carries the crossing by that contract's version
and both own `crates/contracts/`, and through M5-11 on M5-10, because it
carries the history by its type.

If a reason cannot be stated without choosing something the record leaves to a
metric's task, or without changing the record's closed set, that is an
escalation.
